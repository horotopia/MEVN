# MEVN Documentation

## Description

Ce projet est une application utilisant le stack MEVN (MongoDB, Express.js, Vue.js, Node.js). Il s'agit d'une application de e-commerce permettant de gérer les utilisateurs, les produits et les commandes.  
L'API RESTful permet de gérer les utilisateurs, les produits et les commandes. L'API est sécurisée avec JWT (JSON Web Tokens) et intègre des fonctionnalités de paiement avec PayPal et Stripe.
Le client est une application Vue TypeScript permettant de visualiser les produits, de les ajouter au panier et de passer des commandes. Le client est sécurisé avec Vue Router et Vuex.
